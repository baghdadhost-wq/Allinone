# قوالب الواجهة الرسومية

| الملف | متى يُستخدم | المتغيرات |
|---|---|---|
| `deep_thinking.txt` | عند تفعيل «التفكير بعمق» | `[ينقل السؤال هنا]` يُستبدل بسؤالك |
| `memory.txt` | عند تفعيل Memory | `{transcript}` نص المحادثة · `{file}` مسار ملف txt · `{message}` رسالتك |

عدّل النص كما تريد، ويُطبَّق التعديل على الرسالة التالية مباشرة دون إعادة تشغيل.
يرى المستخدم سؤاله فقط، والنص الكامل يظهر عند تفعيل «إظهار النص المرسل».
