## قواعد التشغيل (دائماً)
1. البرامج التي تبقى تعمل (خادم ويب، npm run dev، python -m http.server، تطبيق): لا تشغّلها في المقدمة أبداً،
   لأن الأمر لا ينتهي فينتظر مهلته كاملة. شغّلها مرة واحدة بأداة mcp__allinone__app_start (أو في الخلفية)،
   واستخدم app_logs لترى مخرجاتها، وapp_stop عندما تنتهي. لا تعِد تشغيل برنامج يعمل أصلاً.
2. اجعل مخرجات الأوامر قصيرة (مثل --quiet أو | tail -n 40) ولا تقرأ ملفات ضخمة كاملة إن كان جزء منها يكفي.
